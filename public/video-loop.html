Nickii AI - Video Loop Mode

This is a standalone version that plays a video in a continuous loop without requiring a server connection.

To add your video: Place your video file (e.g., nickii-loop.mp4) in the same folder as this HTML file, or edit the video source in the code.

To enable sound: Tap anywhere on the screen. iOS requires user interaction for unmuted autoplay.

For best results: Add this page to your Home Screen and use Guided Access to prevent exiting.
